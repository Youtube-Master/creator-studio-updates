# Creator Studio 업데이트

설치된 Creator Studio 앱이 새 버전을 받아 가는 곳입니다. 앱은 켤 때와 6시간마다 `latest.json`을 확인하고,
새 버전이 있으면 설치 파일을 받아 서명을 확인한 뒤 알아서 설치합니다.

- `latest.json`: 최신 버전 정보(서명됨)
- `releases/`: 설치 파일(최근 2개)
- `CHANGELOG.md`: 버전별 바뀐 점

**이 저장소의 이름을 바꾸거나 지우거나 비공개로 바꾸면 자동 업데이트가 멈춥니다.**

처음 설치하거나 직접 다시 설치하려면 `releases/`의 최신 `CreatorStudio-Setup-*.exe`를 받아 실행하세요.
